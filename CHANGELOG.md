# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-03

### Added
- Created the project structure and setup Next.js app configurations.
- Integrated **Vapi Voice Assistant SDK** for voice consultation functionality.
- Integrated **Gemini Flash AI model** (`gemini-flash-latest`) for custom workout and diet programs generation.
- Added **Convex real-time database schema** mapping for plans and users.
- Built **Interactive Profile Dashboard** to view current workout routines, streak count, daily macros, and calorie completion gauges.
- Implemented **BMI Calculator** card enabling fast weight categorization checks directly on the profile page.
- Implemented **Water Intake Tracker** tool to record daily water cups consumption.
- Added **Download Plan (PDF)** features supporting clean print styles for all routines and nutrition cards.
- Integrated **Clerk Authentication** hooks and provider matching guest-fallback parameters.
